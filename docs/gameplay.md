# ゲーム仕様

最終確認: 2026-09-12

## 目的と進行

- 地下100階の最終ボスを倒すと踏破。
- 10〜90階の階層主撃破後、未所持の実用遺物から重複なしで最大3個を提示し、1つ選ぶ。候補が足りなければ実数だけ表示する。百景の鍵（r10）は100階踏破時に授与し、既に旧版で取得した鍵は保持する。
- 10階ごとに帰還または継続を選べる。
- 死亡時は冒険中のレベル、装備、持ち物、金貨を失う。図鑑、称号、熟練度、最高記録、墓は残る。

## 戦闘

- 敵の次行動を表示する。通常攻撃、強攻撃、防御、溜め、状態異常がある。
- プレイヤーは攻撃、防御、職業技、回復薬、爆裂石、道具袋、逃走を選ぶ。
- 防御は大技・状態異常への主な対抗手段。
- 毒、出血、呪い、暗闇、麻痺がある。
- 状態異常は残りターン、効果、解除方法をステータス欄へ表示する。暗闇では攻撃失敗、麻痺では回復薬以外の行動失敗が起こり得る。
- 回復薬は最大3個。開始時1個、最大HPの45%か最低18HPを回復し、使用時も敵の行動が進む。
- 爆裂石は一発逆転用の攻撃アイテムで、所持上限は2個。
- 道具袋は合計5個まで。万能薬は全状態異常、解呪札は呪い、止血布は出血を解除し、星蜜はMPを10回復する。火炎瓶・氷結札・雷鳴玉は属性攻撃、煙玉は階層主以外からの確実な逃走に使う。
- 万能薬、属性攻撃道具、解呪札、止血布、星蜜を使うと1手進む。煙玉は即座に戦闘を終了する。解除対象がない、MPが満タン、階層主戦など効果のない状況では使用できず、消費もしない。
- 通常逃走または煙玉で逃げ切った敵は、同じ階の離れた通路へ戻る。討伐には数えず、探索を続ければ再遭遇することがあるが、逃走直後の1歩で同じ敵と再戦にはならない。
- プレイヤーのHP・MPは数値と10分割の宝石ゲージを併記する。端数は最後の区画を部分点灯し、HP半分以下では赤い区画を明滅させる。
- 弱点攻撃は1.35倍、耐性攻撃は0.55倍。敵が「身構える」予告中はプレイヤーの攻撃も軽減される。
- 状態異常予告を防御した場合、付与そのものは受けるが持続を3ターンから1ターンへ抑える。
- 戦闘演出はコマンドIDから決める。攻撃系は剣、防御・鉄壁・守りの祈り・盾技は盾、魔法は詠唱、僧侶の治療と回復薬は道具使用、爆裂石は投擲、逃走は離脱の姿になる。賢者の大治療と雷撃はどちらも詠唱する。
- 敵HPはプレイヤー攻撃の着弾時、プレイヤーHPは敵攻撃の着弾時に表示へ反映する。内部の戦闘計算と自動保存は先に確定し、表示待ちの間に二重入力できないよう手番中はコマンドを止める。

## 地下の十景

| 階 | 地域 | 景観 |
| --- | --- | --- |
| 1〜10階 | 苔むす入口 | 苔と地上光が残る入口 |
| 11〜20階 | 赤錆坑道 | 鉄錆と廃坑の筋 |
| 21〜30階 | 水没回廊 | 水紋と青い反射 |
| 31〜40階 | 紫晶脈 | 紫の結晶と毒光 |
| 41〜50階 | 白骨墓廊 | 白骨と墓標 |
| 51〜60階 | 焔脈炉 | 熔岩の亀裂と火の粉 |
| 61〜70階 | 氷哭洞 | 氷晶と冷たい青光 |
| 71〜80階 | 呪祭壇 | 呪印と紫紅の祭壇 |
| 81〜90階 | 星無き淵 | 光の沈む虚空 |
| 91〜100階 | 奈落王城 | 金の紋と暗赤の王城 |

各地域は地図の岩・床・装飾・光、戦闘背景、地域名表示を共有する。BGMは探索、通常戦闘、階層主、商店の既存主旋律を保ち、地域ごとに音域、主音色、対旋律、低音の脈動を変える。発音密度が高い地域ほど各音を抑え、深層が単純な大音量にならないよう均衡する。

### 1〜20階の攻略差

- 洞ミミズ：溜めの次に締めつけ。強攻撃を防御する。
- 苔スライム：HP半分で1回だけ分裂回復。半分付近から大技で仕留める。
- 骨ネズミ：通常攻撃が二連噛み。長期戦を避ける。
- 夜コウモリ：与えた傷の35%を吸収する。
- 穴ゴブリン：攻撃時に階層相当の金貨を盗む。
- 岩トカゲ：甲殻防御中は攻撃を18%まで軽減する。
- 亡者の鎧：身構え中に攻撃すると呪いの反撃を受ける。
- 火喰い虫：炎攻撃を吸収して回復し、氷に弱い。
- 影オオカミ：HP25%以下で強攻撃中心へ変化する。
- 深層の目：状態異常予告では暗闇を与える。
- 10階と20階の階層主は固定行動パターンを持ち、HP半分以下で別パターンへ変わる。

### 21〜100階の攻略差

- 泥王子：状態異常予告で暗闇。防御で持続を短縮する。
- 硝子蜘蛛：毒糸で毒。状態異常予告を防御する。
- 空洞兵：盾壁中は攻撃を25%まで軽減する。
- 灯火鬼：強攻撃の火柱がさらに18%強くなる。溜めの後を防御する。
- 鉱脈蛇：攻撃時にMPを奪う。技を早めに使って短期決戦にする。
- 月喰い蛾：状態異常予告で麻痺。
- 墓守犬：状態異常予告で出血。
- 黒潮魚：プレイヤーの守備を45%だけ参照して攻撃する。
- 裂け兎：通常攻撃が三連撃扱いで22%強くなる。
- 鉄殻亀：身構え中に攻撃すると出血の反撃を受ける。
- 奈落蜂：通常攻撃にも一定間隔で麻痺が混じる。
- 鏡面騎士：炎・氷・雷・聖の攻撃を反射する。物理か爆裂石を使う。
- 星屑蛙：身構え・溜めのたび最大HPの8%を再生する。
- 虚ろ司祭：状態異常予告で呪い。
- 深淵の手：プレイヤーHP35%以下では攻撃が30%強くなる。

通常・凶暴・呪染・深淵は同じ素体でも別個体として扱う。凶暴は攻撃・強攻撃中心、呪染は呪い行動、深淵は強攻撃と麻痺行動を加える。弱点と耐性も変異ごとに変わる。21階以降は階層帯に応じて出現可能な素体・変異が広がり、81〜100階では全25素体・4変異が候補になる。

### 階層主

全10体が固有の前半パターンとHP半分以下の後半パターンを持つ。炎吸収、魔法反射、瀕死連撃、再生、暗闇、守備貫通、三連撃、瀕死狩りなど、各区間で学んだ通常敵の判断を複合して試す。戦闘画面では階層主の攻略法、弱点、耐性を最初から表示する。100階は攻撃・防御・状態異常・溜め・強攻撃の5予告をすべて使う。

10階ごとの階層主撃破後は「さらに深く潜る」を最初の主操作とする。「地上へ帰還する」は副操作として分離し、一度押すと冒険終了・ランキング登録を説明する確認欄を開く。最終確認を押した場合だけ帰還を確定し、確認欄から潜行継続へ戻れる。

### 図鑑の情報開示

- 未遭遇：影だけ。
- 遭遇：名前と出現階。
- 1体討伐：弱点と耐性。
- 3体討伐：固有行動と兆候。
- 5体討伐：具体的な攻略法。

## 探索と経済

- 3階ごとに商店。回復薬は各店1個、価格は階層帯により上昇する。
- 階移動時に最大HPの18%とMP3を回復する（遺物で増加可能）。
- 宝箱から金貨、回復薬、爆裂石、道具袋用消耗品、装備を得る。道具袋が5個なら新しい消耗品は14Gへ変換し、装備の持ち物が一杯なら装備を金貨変換する。
- 装備は攻撃・守備・HP・MPに加え、吸血、会心、防御反撃、MP循環、状態耐性、瀕死強化のいずれかを持つ。複数部位の同種効果は加算する。
- 商店と持ち物では現在装備との差と特殊効果を購入・装備前に表示する。
- アイテム一覧は全100件の名前と分類を最初から表示し、詳細効果は一度入手した後に開示する。

## 初回案内

- 通常プレイの初回だけ、移動、敵予告、防御、状態異常、回復を実際の場面で順に案内する。
- スマートフォンではタップと十字キー、PCでは矢印/WASDとクリックを説明する。
- 案内はゲーム操作を止めない小窓とし、1件ずつ閉じられる。まとめて終了でき、フッターから再表示できる。
- MP不足、道具未所持、階層主から逃走不能などは、該当コマンド内に理由を表示する。

## 再挑戦と恒久進行

- 死亡階に墓と遺品喰らいが現れる。倒すと前回の装備・持ち物から1個を回収できる。再死亡で前の墓を置き換え、新しい遺品がなければ墓なしとする。回収時に持ち物8枠が一杯なら、回収画面内で不要品を整理してから1品を回収する。
- 熟練度は職業の使用で進み、称号・職業などの解放に使う。大きな恒久能力上昇には使わない。
- 50階到達後の次回開始から侍を選べる。居合斬りは高威力の物理技、見切りは次の敵攻撃を大きく軽減する。
- 80階到達後の次回開始から錬金術師を選べる。爆薬調合は爆裂石に似た大打撃、再生調合はHP・MP回復と状態異常解除を同時に行う。
- 深層職の解放はMetaへ残るが、能力値の恒久上昇は行わない。新職業の技も通常の1ターン消費と敵予告処理に従う。
- テストモードは開発確認専用。通常の最高階・得点・討伐数・踏破・熟練度・称号・図鑑・墓・匿名テスト記録・オンラインランキングには反映しない。既存ADRで認めた到達階による職業解放だけを残す。すでに混在した旧Metaは推測で消さない。

### 終了結果と依頼進行

- 通常プレイの死亡・中断・帰還・踏破後は、ランキング画面の上部とタイトル画面に終了結果を表示する。
- 死亡時は、到達階、敵の実行した予告、死因（強攻撃、状態異常、魔法反射、通常攻撃）と、次回の対処助言を表示する。敵名は魔物の安定IDから現在の表示言語で導出する。
- 死亡して墓が作られた場合は、墓の階、失った品数、回収候補を表示する。墓が空の場合は回収欄を出さない。
- 地下依頼は `slay` が討伐8体、`descend` が地下10階、`chests` が宝箱3個を目標とし、探索中に現在値と達成状態を表示する。宝箱だけは冒険全体の `chestsOpened` 累計を使い、階移動で達成を取り消さない。
- 終了時は今回の熟練度加算後の値と、次に解放される称号・必要値を表示する。熟練度による大幅な恒久能力上昇は行わない。

### 奈落降下（安全地点への別ルート）

- 通常プレイで階層主を倒すと、その次の階を「安全地点」として記録する。10階の階層主なら11階、40階なら41階で、最終到達地点は91階までとする。
- タイトル画面の「奈落降下」は、最初の階層主を倒すまでロックされる。テストモードの討伐では解放・更新しない。
- 奈落降下は、本編Runを作る前に遊ぶ20秒の連続移動型落下ゲーム。指の左右スライド、左右ボタン長押し、矢印/A・D長押しで移動する。岩と蝙蝠を避け、金色の補給箱を取る。最初に操作と見分け方を表示してから開始する。
- 左右から張り出す大岩を交互に配置し、端に居続けるだけでは成功できない構成にする。被弾は3回まで。被弾後1.1秒は無敵で連続事故を防ぐ。進行バー・残り秒数・補給数・残り耐久を常時表示する。
- 一時停止ボタンまたはスペースで停止できる。タブが隠れた時・ウィンドウのフォーカスを失った時は自動停止し、明示的な再開まで進めない。低フレームレートでも通過した障害物の判定を飛ばさない。
- 失敗時は地上へ戻るだけで、冒険中の装備・記録・墓を失わない。成功時は安全地点から再開するが、通常の到達ワープにはしない。
- 降下後のRunは、安全地点×1.65切り上げ（上限151）のレベル、同区間段階・商店相当の鍛造補正を持つ貸与装備で開始する。回復薬2個（無傷または補給箱3個以上なら3個）、爆裂石1個（箱2個以上なら2個）、星蜜1個（箱4個以上なら2個）を支給する。貸与装備は売却、図鑑の入手記録、墓の回収候補の対象外で、より良い装備を得ると返却される。
- 奈落降下ルートの死亡・中断・帰還・踏破は、通常のMeta進行、熟練度、図鑑、墓、職業解放には反映するが、総合オンラインランキングには送信しない。通常ルートの高得点・収集・ランキング価値を残すためである。
