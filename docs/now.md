# 現在地

最終更新: 2026-09-12

## 公開中

- ゲーム: `https://chika-hyakkei.github.io/`
- ランキング API: `https://chika-hyakkei-ranking.chika-hyakkei.workers.dev`
- 公開経路: GitHub `main` へのpush → GitHub Actions → GitHub Pages

## 現在の機能

- 100階踏破を目標にしたブラウザローグライク
- 8職業、100体の魔物図鑑、100アイテム、階層主・遺物・墓・熟練度
- 敵行動予告、防御、状態異常、回復薬上限3、爆裂石
- タップ移動、矢印/WASD移動、戦闘ショートカット
- 端末内の匿名テスト記録
- 終了時に自動記録する総合オンラインランキング
- タイトル画面の最新更新要約と総合ランキングTOP3
- 左上のロゴ画像（`public/assets/title-logo.webp`）
- Cloudflare Web Analyticsによる匿名のアクセス集計
- Runの直前バックアップ、破損データ隔離、黒画面時の復旧画面
- ランキング通信失敗時の端末保留、次回起動時再送、重複登録防止
- ステータス・戦闘画面の短い10分割宝石HP/MPゲージ
- 初回だけの移動・予告・防御・状態異常・回復案内
- 25素体・4変異の固有攻略と、全10階層主のHP段階別パターン
- 遭遇・1・3・5体討伐で情報が増える段階開示式の魔物図鑑
- 端末言語判定、日本語・英語の手動切替、日本語フォールバックを持つ翻訳基盤
- 地下依頼を言語非依存IDで保存し、旧日本語セーブから自動移行
- 装備80件を共通アイテムマスターから生成し、吸血・会心・防御反撃・MP循環・状態耐性・瀕死強化を実戦へ接続
- 商店・持ち物の装備比較と、Metaに残るアイテム入手済み記録
- 万能薬、3属性攻撃、煙玉、解呪札、止血布、星蜜を宝箱・道具袋・戦闘へ接続
- 本番と同じ着地・敵・戦闘処理を使う、8職業×10,000固定シードの奈落降下後2連戦計測
- 戦闘コマンドID別の攻撃・盾・魔法・回復・投擲・逃走ポーズと、着弾に同期するHP表示
- `/en/` から直接開ける英語版と、探索・戦闘・商店・図鑑・ランキング・案内・全マスターデータの英語表示
- ボス撃破後の潜行継続を主操作にし、帰還だけを二段階確認にする誤操作防止
- 終了結果の死因・次回助言・墓候補・依頼進行・次の熟練度解放表示
- 50階解放の侍、80階解放の錬金術師と固有技・戦闘演出・日英表示
- パスワード付きT入口、全職業を選べるテストモード、最強状態/初期状態の階層ジャンプ
- PWAマニフェスト、ホーム画面追加用メタデータ、ゲームシェルのオフラインキャッシュ
- 通常ボス後の安全地点を使う「奈落降下」：20秒の連続操作で岩と蝙蝠を避け、補給を取って貸与装備で安全地点から再開
- 奈落降下ルートは通常のMeta進行・墓・職業解放を維持しつつ、総合ランキングから分離

## 直近の注意

- ランキングはカジュアル用途。クライアント申告値を受け取るため大会級の不正対策は未実装。奈落降下ルートは開始条件が異なるため総合ランキングへ送らない。
- テストモードはランキング・匿名テスト記録の対象外だが、到達階に応じた深層職の解放はMetaへ反映される。通常プレイの死亡・中断・帰還・踏破は自動記録される。
- `promo/` と `social/` は未追跡の制作素材。明示的な依頼がない限りコミットしない。
