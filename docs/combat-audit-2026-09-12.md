# 奈落降下・着地後の実戦ルール検証

実施日: 2026-09-12

## 条件

- 本番と同じ `createCheckpointRun`、`enemyFor`、`resolveBattleAction`、`resolveEnemyTurn` を使用。
- 固定シード10,000種類 × 8職業 = 80,000試行。各シードを9安全地点へ均等に割り当て、各職業・地点で1,111〜1,112試行。
- 生成された階の通常敵2体と連戦。回復薬・爆裂石・星蜜・遺物なし、階移動回復なし。実際の着地では回復薬2〜3個、爆裂石1〜2個、星蜜1〜2個が付く。
- 敵予告を見て1手先のHP/MP・敵HPの変化から行動を選ぶAI。人間の初見プレイではなく、乱数も既知の検証用方策。
- レベルは安全地点×1.65切り上げ（上限151）。貸与品は同区間の段階と商店相当の鍛造補正。敵本体の数値は変更していない。
- 80ターンで終わらない戦闘は `stalemate` として別記録。AIが回復を繰り返す場合もあるため、未撃破をすべて理不尽死と扱わない。

## 91階での結果

| 職業 | 1戦突破 | 2連戦突破 | 終了時平均HP | 終了時平均MP |
| --- | ---: | ---: | ---: | ---: |
| warrior | 100.0% | 99.5% | 373.8 | 296.0 |
| thief | 99.9% | 84.9% | 215.4 | 297.6 |
| priest | 95.9% | 89.8% | 449.6 | 287.8 |
| mage | 99.8% | 99.5% | 574.0 | 311.9 |
| knight | 100.0% | 100.0% | 536.8 | 304.4 |
| sage | 99.9% | 99.6% | 684.7 | 307.8 |
| samurai | 100.0% | 100.0% | 425.3 | 299.8 |
| alchemist | 100.0% | 100.0% | 417.0 | 303.9 |

全地点・全職業で1戦突破率85%以上、2連戦突破率65%以上という今回の回帰下限を通過した。91階では盗賊と僧侶が他職より苦しいため、実際の支給薬を含む区間攻略を次の比較対象とする。通常プレイの到達時レベル分布から貸与値を最適化した結果ではなく、着地直後の詰みを抑える暫定調整である。

## 再実行

`npm run test:balance`（10,000シード、JSON出力）

小さく試す場合: `node scripts/combat-audit.mjs --seeds=900`

## 言えないこと

この計測は通常ルートの1〜100階通し探索、商店の購入AI、全装備ビルド、初見プレイヤーの到達率を評価していない。従来の抽象シミュレーターの3〜5%／10〜15%という数値を現行ゲームのクリア率としては使用しない。旧モデルは `npm run test:balance:abstract` として仮説確認用途に残す。
